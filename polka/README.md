# Полка

Сказал мысль вслух - она уже разложена по местам и вернётся к тебе тогда, когда нужна.

Ловит мысль в любом виде, сама решает, что это и насколько важно, кладёт на нужную
полку и напоминает так, что пролистать не выйдет. Важные идеи разворачивает в готовое
задание для Claude Code.

## Что внутри

| Часть | Где живёт | Что делает |
|---|---|---|
| Бот | `polka/bot.py` | принимает текст и голос, показывает карточку с кнопками |
| Разбор | `polka/brain.py` | Claude решает полку, важность, нужно ли напоминание |
| Напоминания | `polka/flow.py`, `polka/scheduler.py` | эскалация, тихие часы, подтверждение вместо смахивания |
| API и статика | `polka/api.py` | мини-приложение, точка входа для команды на айфоне |
| Мини-приложение | `miniapp/` | серый интерфейс с физическими плитами |
| Подключение | `polka/setup.py`, `miniapp.sh` | туннель, кнопка меню у бота, шаги для BotFather |
| Настройка | `polka/wizard.py` | спрашивает три ключа и проверяет каждый на живых сервисах |

## Как это работает

**Захват.** Пишешь или диктуешь мысль. Claude возвращает карточку: заголовок, суть,
полка, важность от 1 до 5, нужно ли напоминание. Если он не уверен в важности или сроке,
он не гадает, а спрашивает одним рядом кнопок.

**Важность как вес.** В интерфейсе важность это не цветной ярлык, а свет и толщина:
пятёрка светлее и толще единицы. Полка целиком светится по своей самой важной мысли.

**Напоминание, которое не пролистаешь.** Обычное напоминание приходит один раз.
Важное (4) возвращается через 30 и 60 минут, если не нажать кнопку. Пятёрка возвращается
через 15, 25 и 45 минут, и на втором заходе шлёт вдогонку второе короткое сообщение,
чтобы телефон дёрнулся дважды. Закрывается напоминание только явным нажатием
«сделал»: смахивание уведомления ничего не закрывает.

**Тихие часы.** С 23 до 8 не приходит ничего, кроме важности 5. Остальное ждёт утра.

**Мост к Claude Code.** У идеи, которую можно построить, появляется кнопка
«развернуть в задание». Claude превращает брошенную фразу в подробное ТЗ: что строим,
сценарий пользователя, стек, объём первой версии, открытые вопросы. Файл прилетает
в чат, текст можно скопировать из приложения.

## Запуск

```bash
cd polka && ./miniapp.sh              # Windows: двойной клик по miniapp.bat
```

Одна команда на всё. При первом запуске мастер спросит три вещи и каждую сразу
проверит на живых сервисах:

1. **токен бота** - сверяется через `getMe`, неверный не примет и переспросит
2. **chat id** - определяется сам: попросит написать боту любое слово и вычитает
   id из `getUpdates`
3. **ключ Anthropic** - проверяется двумя запросами: принят ли ключ и есть ли на
   счету кредиты. Без кредитов разбор падал бы молча, поэтому это ловится сразу.
   Ключ можно пропустить: Полка будет работать без сортировки.

Проверенное ложится в `polka/.env`. Дальше скрипт поднимает Полку, выдаёт
временный https-адрес и вешает кнопку мини-приложения боту.

Настроить, ничего не запуская: `python3 -m polka.wizard`.
Запустить без мини-приложения: `./run.sh`.

Полка держит бота, планировщик и веб-сервер в одном процессе. Пока окно открыто,
напоминания приходят. Закрыл окно - тишина.

Проверить разбор, ничего никуда не отправляя:

```bash
python3 -m polka --dry --capture "надо продлить домен до пятницы"
```

## Мини-приложение в Telegram

Одна команда поднимает Полку, выдаёт временный https-адрес и прописывает
кнопку боту:

```bash
cd polka && ./miniapp.sh          # Windows: двойной клик по miniapp.bat
```

Что она делает по шагам: ставит зависимости, поднимает туннель через
cloudflared (предложит скачать, если его нет), вызывает у бота
`setChatMenuButton` с адресом приложения, записывает адрес в `.env`,
перечитывает его у Telegram и убеждается, что сохранилось именно то.

После этого открой бота в Telegram: слева от поля ввода появится кнопка
**Полка**. Это и есть рабочее мини-приложение, отдельная регистрация ему
не нужна.

Если адрес уже свой (домен, сервер), туннель не нужен:

```bash
python3 -m polka.setup --url https://твой-домен
```

**Про временный адрес.** Туннель живёт, пока открыто окно. Закрыл - адрес
пропал, кнопка ведёт в никуда. Для постоянной работы нужен свой домен или
сервер: тогда `POLKA_PUBLIC_URL` прописывается один раз и `polka.setup`
запускается однократно.

### Короткая ссылка t.me/бот/polka

У бота нет прав завести себе короткую ссылку: `/newapp` принимается только
от твоего аккаунта. Скрипт печатает готовые шаги в конце работы, повторить
их надо один раз в @BotFather:

```
/newapp  ->  выбрать своего бота
название:      Полка
описание:      Мысли по полкам
картинка:      640x360
ссылка:        адрес из скрипта
короткое имя:  polka
```

После этого приложение открывается по прямой ссылке и появляется в профиле бота.

### Пересборка интерфейса

Собранная версия лежит в `static/` и коммитится, чтобы Полка запускалась без
Node.js. Пересобирать нужно только после правок в `miniapp/`:

```bash
cd polka/miniapp && npm install && npm run build
```

## Двойное касание задней крышки

Самый быстрый путь: касание, фраза, готово. Телефон при этом можно не разблокировать
дальше экрана команд.

**1. Команда быстрого доступа** (приложение «Быстрые команды», новая команда):

1. `Диктовка текста` - язык русский, остановка по паузе.
2. `Получить содержимое URL`:
   - адрес: `https://твой-адрес/api/capture`
   - метод: `POST`
   - заголовки: `X-Polka-Token` = значение `POLKA_CAPTURE_TOKEN`
   - тело запроса: JSON, поле `text` = результат диктовки
3. Назови команду «Полка».

**2. Двойное касание:** Настройки → Универсальный доступ → Касание → Касание задней
панели → Двойное касание → выбери «Полка».

Мысль уходит на сервер, Claude её разбирает, карточка приходит в Telegram.

## Голосовые в чате

Telegram не расшифровывает голос для ботов. Если задан `OPENAI_API_KEY`, Полка гоняет
голосовое через Whisper. Без ключа она честно просит прислать текстом и предлагает
диктовку через команду быстрого доступа, где расшифровывает сам айфон.

## Тесты

```bash
python3 polka/tests/test_polka.py     # ядро: 22 теста
python3 polka/tests/test_setup.py     # подключение мини-приложения: 12 тестов
python3 polka/tests/test_wizard.py    # мастер настройки: 9 тестов
```

Первый файл проверяет разбор карточки, границы значений, эскалацию напоминаний,
тихие часы и подпись Telegram WebApp. Второй поднимает локальный макет Bot API и
следит, что боту уходит ровно тот запрос, который нужен, что результат
перечитывается после записи и что http вместо https отбивается до отправки.

## Безопасность

- Токен бота и ключи живут только в `.env`, он не коммитится.
- Мини-приложение проверяет подпись `initData` по HMAC и сверяет id пользователя
  с `POLKA_CHAT_ID`: чужой аккаунт не увидит полки.
- Команда с айфона ходит по отдельному секрету `POLKA_CAPTURE_TOKEN`, сверка
  идёт постоянным по времени сравнением.
- Бот отвечает только на сообщения из своего чата.

Если токен где-то засветился, сделай `/revoke` у @BotFather и впиши новый.
