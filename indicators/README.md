# FVG Sniper — TradingView индикатор (Pine Script v6)

Индикатор под модель **«анализ на 5m → вход на 3m»**: HTF Fair Value Gap как точка интереса,
свип ликвидности как триггер, SMT-дивергенция и LTF-подтверждение как фильтры.

Файл: [`fvg_sniper.pine`](fvg_sniper.pine)

## Установка

1. TradingView → **Pine Editor** (внизу экрана).
2. Открыть `fvg_sniper.pine`, скопировать весь код, вставить в редактор.
3. **Save** → назвать (например `FVG Sniper`) → **Add to chart**.
4. Поставить график на **3m** (таймфрейм входа). В настройках `Analysis timeframe` оставить **5**.

> Важно: график должен быть **младше** таймфрейма анализа. Если поставить график на 5m и выше,
> в панели появится предупреждение `⚠ analysis TF ≤ chart TF`.

## Логика сигнала

Сигнал — это подтверждённая последовательность, а не один паттерн:

| # | Компонент | Что проверяется |
|---|-----------|-----------------|
| 1 | **HTF FVG (5m)** | Цена зашла в неотработанный имбаланс 5m (гэп между `high[3]` и `low[1]`). Держится `poiValid` баров. |
| 2 | **Свип ликвидности** | Хвост снял свинг-хай/лоу (пивот длиной `pivotLen`), но тело закрылось обратно внутрь. Живёт `sweepValid` баров. |
| 3 | **LTF подтверждение (3m)** | Появился FVG на таймфрейме входа **или** дисплейсмент-свеча (тело > ATR14 × `dispMult`), закрывшаяся за экстремум свипа. |
| 4 | **SMT** | В момент свипа коррелирующий инструмент **не** снял свой аналогичный уровень → дивергенция. |
| 5 | **HTF bias** | Цена 5m выше/ниже EMA(`biasLen`) на 5m. |

Каждый выполненный пункт даёт +1 к **score**. Сигнал срабатывает, когда `score >= Confluences required`
(по умолчанию 3 из 5) **и** пройдены жёсткие фильтры (`Require liquidity sweep`, `Require SMT`,
`Only trade with HTF bias` — то, что включено, обязательно).

Лонг и шорт никогда не выдаются на одном баре; между сигналами действует `cooldown` баров.

## Уровни сделки

- **Entry** — закрытие сигнальной свечи.
- **Stop** — за минимум/максимум свипа или за границу HTF FVG (что дальше) минус `ATR14 × slAtrPad`.
- **TP1 / TP2** — фиксированные множители риска (`2.0R` и `3.5R` по умолчанию).

Рисуются красный бокс риска, зелёный бокс профита, линия входа и пунктир TP1.

## Настройки

| Группа | Ключевое |
|--------|----------|
| **1 · Analysis timeframe** | ТФ анализа (5m), минимальный размер гэпа в ATR, режим инвалидации (`Close through` / `Wick through` / `50% reached`), сколько FVG хранить на сторону |
| **2 · Entry timeframe confirmation** | требовать LTF FVG и/или дисплейсмент, множитель тела свечи |
| **3 · Liquidity sweep** | длина пивота, срок жизни свипа, отрисовка уровней |
| **4 · SMT divergence** | коррелирующий тикер (`NQ1!`↔`ES1!`, `EURUSD`↔`DXY`, `BTCUSDT`↔`ETHUSDT`), делать ли SMT обязательным |
| **5 · Signal engine** | сколько конфлюенсов нужно, cooldown, EMA-байас |
| **6 · Risk** | отступ стопа в ATR, R-множители целей |
| **7 · Session filter** | торговать только внутри сессии (килзоны), таймзона, подсветка фона |
| **8 · Appearance** | цвета, положение дашборда |

## Алерты

Через **Create Alert → Condition: FVG Sniper**:

- `Long signal` / `Short signal` — динамическое сообщение с entry / SL / TP1 / TP2 / score
  (приходит через `alert()` — выбирайте `Any alert() function call`);
- `Sweep of lows` / `Sweep of highs` — только свип ликвидности;
- `Bullish SMT` / `Bearish SMT` — только SMT-дивергенция.

Все алерты — по закрытию бара (`once_per_bar_close`), сигналы не перерисовываются.

## Дашборд

Таблица в углу графика показывает по каждой стороне (L / S) статус всех пяти компонентов,
текущий score против требуемого и параметры последнего сигнала.

## О перерисовке

- HTF FVG регистрируются только по закрытию бара 5m (`barstate.isconfirmed`) и по данным
  `request.security` с `lookahead_off` — гэп берётся из уже закрытых свечей `[1]`…`[3]`.
- Свипы и сигналы считаются от закрытия бара 3m.
- В процессе формирования текущего бара сигнальная стрелка может появиться и исчезнуть —
  это нормально, окончательным считается состояние на закрытии.

## Пресеты

**Скальпинг индексов (NQ/ES, 3m):** `Analysis TF 5`, свип обязателен, SMT включён (`ES1!`),
`Confluences required 4`, сессия `0930-1130 America/New_York`.

**Крипта (BTC/ETH, 3m):** `Analysis TF 5`, SMT `BINANCE:ETHUSDT`, `minGapAtr 0.2`,
`Confluences required 3`, сессия выключена.

**Меньше сигналов:** поднять `Confluences required` до 4–5, включить `Only trade with HTF bias`
и `Require SMT divergence`, увеличить `minGapAtr`.
