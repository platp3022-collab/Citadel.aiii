# FVG Sniper — TradingView индикатор (Pine Script v6)

Карта имбалансов для модели «анализ 5m → работа на 3m». Индикатор **не даёт сигналов
и не рисует точки входа** — он только показывает структуру: где имбалансы, где они
совпали, где сняли ликвидность и где разошлись коррелирующие инструменты.

Файл: [`fvg_sniper.pine`](fvg_sniper.pine)

## Установка

1. TradingView → **Pine Editor**.
2. Скопировать весь код из `fvg_sniper.pine`, вставить, **Save** → **Add to chart**.
3. График поставить на **3m**, в настройках `ТФ анализа` оставить **5**.

## Что рисуется

### 1. FVG двух таймфреймов

- **FVG 5m** — зона с рамкой и жирными линиями границ.
- **FVG 3m** (таймфрейм графика) — та же зона, но полупрозрачнее и без рамки.
- У каждой зоны рисуются **линия верхней границы, линия нижней границы и пунктир 50 % (CE)** —
  чтобы гэп читался как коридор между двумя уровнями, а не как размытое пятно.
- Зоны тянутся вправо и продлеваются на несколько баров вперёд (`Продлевать зоны вправо`).
- Снимаются по выбранному правилу: закрытие за границей / прокол хвостом / достижение 50 %.
  Отработанные можно оставлять серыми (`Оставлять отработанные`).

### 2. GAP — два FVG на одном уровне

Главное, ради чего всё: когда **FVG 5m и FVG 3m перекрываются по цене**, область их
пересечения выделяется отдельным ярким боксом с жирной рамкой и подписью **`2×FVG`**.

Настройка `Какие пары считать`:

| Режим | Что ищет |
|-------|----------|
| `5m + 3m` *(по умолчанию)* | только пары «FVG анализа × FVG графика» |
| `Любые два` | любое перекрытие двух FVG одного направления |
| `Только 5m` | стакнутые имбалансы внутри 5m |
| `Только 3m` | стакнутые имбалансы внутри 3m |

`Мин. толщина наложения (× ATR)` отсекает пересечения в пару тиков — подними, если
зон получается слишком много. Зона гаснет, когда цена закрывается за её границей.

### 3. Ликвидность и свипы

- Каждый подтверждённый свинг (пивот длиной `Длина пивота`) даёт уровень ликвидности —
  пунктирная линия, которая **тянется вправо, пока уровень не снимут**.
- Свип = хвост вышел за уровень, а закрытие вернулось обратно. В этот момент линия
  становится **сплошной и цветной**, а на баре появляется подпись **`SWEEP ↑ BSL`** или
  **`SWEEP ↓ SSL`**.
- Снятые уровни остаются на графике `Держать снятый уровень` баров, потом убираются.

Если свипов не видно — уменьши `Длина пивота` (5 → 3), тогда уровней будет больше.

### 4. SMT-дивергенция

**Чтобы SMT появился, нужно заполнить поле `Коррелирующий инструмент` в разделе 6** —
без тикера считать не с чем, и в панели будет оранжевая надпись `укажите тикер в п.6`.

Примеры пар: `NQ1!` ↔ `ES1!`, `EURUSD` ↔ `DXY`, `BINANCE:BTCUSDT` ↔ `BINANCE:ETHUSDT`.

Логика: в момент свипа сравнивается коррелирующий инструмент. Если он **свой аналогичный
уровень не снял** — это дивергенция:

- подпись свипа становится жёлтой и превращается в **`SWEEP ↓ SSL · SMT`**;
- сам уровень перекрашивается в цвет SMT;
- от свинга до бара свипа протягивается **жирная линия SMT** с подписью посередине.

### 5. Панель

В углу — сколько живых FVG 5m и 3m по каждой стороне, сколько активных зон `GAP · 2×FVG`,
сколько баров назад был последний свип и есть ли на нём SMT.

## Алерты

Create Alert → Condition: **FVG Sniper**:

- `GAP: два FVG на одном уровне`
- `Свип максимумов (BSL)` / `Свип минимумов (SSL)`
- `SMT на максимумах` / `SMT на минимумах`

## О перерисовке

- FVG 5m регистрируются только по закрытию бара 5m, данные берутся через `request.security`
  с `lookahead_off` из уже закрытых свечей — гэп не появляется задним числом.
- FVG графика — по закрытию бара 3m.
- Свипы фиксируются по закрытию бара: пока бар живой, подпись может появиться и исчезнуть.

## Если зон слишком много

- подними `Мин. размер (× ATR)` для 3m (0.05 → 0.15);
- подними `Мин. толщина наложения (× ATR)`;
- уменьши `Хранить на сторону`;
- выключи `Показывать FVG графика` — останутся только 5m и зоны GAP.
