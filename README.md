# Citadel.aiii — Мем-коин сканер

Telegram-бот: DexScreener + новостной анализ + алерты в канал/чат. Логика целиком в `memebot.py`.

Есть три режима сканера (пресеты) и **готовый план сделки** в каждом алерте — размер позиции,
стоп, лестница тейков и условия выхода, посчитанные из ликвидности пула и твоего банка.
Разбор логики и честный ответ про «стратегию Kimchi» — в **[KIMCHI.md](KIMCHI.md)**.

## Быстрый запуск (без консоли)

1. Скопируй `.env.example` в `.env` и впиши туда токен и id (см. раздел «Настройка» ниже).
2. Windows — дважды кликни `run.bat`. Mac/Linux — дважды кликни `run.sh`
   (либо `chmod +x run.sh && ./run.sh` в терминале, если двойной клик не запускает).
3. Оставь открытым это окно/терминал — пока бот работает, он сканирует рынок и присылает алерты в Telegram.
   Закроешь окно — бот остановится.

Бот должен работать именно на твоём компьютере (или сервере) — он не может жить в чужом облаке без твоего участия,
и для алертов ему нужен непрерывно работающий процесс.

## Установка вручную

```bash
pip install -r requirements.txt
```

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHANNEL_ID` — канал для алертов (бота нужно добавить туда админом с правом публикации)
- `TELEGRAM_CHAT_ID` — личный chat_id для команд (узнать командой `/id` в чате с ботом)
- `ANTHROPIC_API_KEY` — опционально, для LLM-анализа монет

`.env` не коммитится (см. `.gitignore`) — там живёт настоящий токен бота.

## Запуск вручную

```bash
python memebot.py                              # боевой режим
python memebot.py --once                       # один скан и выход
python memebot.py --dry                        # без отправки в Telegram, всё в консоль
python memebot.py --preset kimchi --bankroll 300   # ранние соланские запуски, банк $300
```

## Режимы сканера (пресеты)

| | `kimchi` | `default` | `safe` |
|---|---|---|---|
| Сети | только Solana | solana/base/bsc/eth | 4 сети |
| Скан | каждые 30с | 60с | 120с |
| Возраст пула | 5 мин – 12 ч | 15 мин – 96 ч | 12 ч – 30 дней |
| Ликвидность | $8k – $400k | $15k – $5M | от $120k |
| Порог алерта | 58 | 65 | 72 |
| Стоп / удержание | −35% / 2 ч | −35% / 4 ч | −25% / 2 суток |

Переключается на лету командой `/preset kimchi` или флагом `--preset`.
`kimchi` = больше алертов, больше мусора, больше риска. Подробности — в [KIMCHI.md](KIMCHI.md).

## План сделки в алерте

Под каждым разбором бот считает конкретный сетап:

- **размер позиции** = `банк × риск% / стоп%`, урезанный потолком на монету и долей от
  ликвидности пула (чтобы твой вход не двигал цену); при риск-флагах размер режется вдвое
- **стоп** и сумма убытка в долларах — до входа, а не после
- **лестница тейков** (+50% / +120% / +300%) и мунбег со стопом в безубытке
- **условия отмены**: цена ниже стопа, ликвидность −30%, доля покупок ниже 45%,
  объём упал ниже минимума, вышло время

Банк задаётся флагом `--bankroll 300`, командой `/bankroll 300` или в `CONFIG["trade"]`.

## Анализ на rug pull

Для монет, близких к порогу алерта, бот дополнительно гоняет проверку контракта:

- **Solana** — [RugCheck](https://rugcheck.xyz): mint/freeze authority, блокировка LP, общий risk score
- **EVM-сети** (ethereum/base/bsc/arbitrum/polygon/avalanche/optimism):
  - [honeypot.is](https://honeypot.is) — можно ли вообще продать токен, налоги на покупку/продажу
  - [GoPlus Security](https://gopluslabs.io) — скрытый/восстанавливаемый овнер, право доминтить токены,
    пауза переводов, чёрные списки, неверифицированный код, концентрация у топ-холдеров, доля овнера/создателя,
    процент заблокированного LP
- Свои эвристики по истории сканов — резкое падение ликвидности (слив LP), объём ≫ ликвидности (wash-трейдинг),
  почти нет продаж (боты), сброс цены после пампа, отсутствие соцсетей

Всё это снижает итоговый скор монеты (`multiplier` в анализе) и попадает в список ⚠️ Риски в тексте алерта —
чем их больше и чем они серьёзнее, тем ниже итоговый score, и явные red flags (honeypot, LP слив) почти обнуляют его.

## Команды бота

`/scan`, `/top [часы]`, `/stats [часы]`, `/status`, `/threshold [0-100]`,
`/preset [kimchi|safe|default]`, `/plan <тикер или адрес>`, `/bankroll [сумма]`,
`/mute [минуты]`, `/unmute`, `/news`, `/id`, `/help`

`/plan WIF` — разбор конкретной монеты с готовым сетапом, даже если она не проходит фильтры
текущего пресета (бот об этом предупредит).

Бот **не торгует за тебя**: он не подключается к кошельку и не имеет твоих ключей.
Все сделки исполняешь сам.

Отказ от ответственности: инструмент фильтрации информации, не финансовый совет.
Подавляющее большинство мем-коинов уходит в ноль.
