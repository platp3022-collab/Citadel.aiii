# Citadel.aiii — Мем-коин сканер

Два независимых бота, оба шлют алерты в один и тот же Telegram (бот/канал/чат):

- **`memebot.py`** — идёт от рынка: сканирует DexScreener (новые пары, бусты), считает скор по
  ликвидности/объёму/моментуму/новостям, дополнительно гоняет проверки на rug-pull.
- **`socialbot.py`** — идёт от рекламы: мониторит Telegram-каналы и YouTube по ключевым словам
  скам-шиллинга, вытаскивает упомянутые тикеры/адреса контрактов, сверяет с реальными
  ончейн-данными и теми же rug-pull проверками, добавляет LLM-вердикт по вероятности скама.

Подробности по `socialbot.py` — в разделе [«Соц-скам-сканер»](#соц-скам-сканер-socialbotpy) ниже.

## Быстрый запуск (без консоли)

1. Скопируй `.env.example` в `.env` и впиши туда токен и id (см. раздел «Настройка» ниже).
2. Windows — дважды кликни `run.bat`. Mac/Linux — дважды кликни `run.sh`
   (либо `chmod +x run.sh && ./run.sh` в терминале, если двойной клик не запускает).
3. Оставь открытым это окно/терминал — пока бот работает, он сканирует рынок и присылает алерты в Telegram.
   Закроешь окно — бот остановится.

Бот должен работать именно на твоём компьютере (или сервере) — он не может жить в чужом облаке без твоего участия,
и для алертов ему нужен непрерывно работающий процесс.

## Установка вручную

```bash
pip install -r requirements.txt
```

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHANNEL_ID` — канал для алертов (бота нужно добавить туда админом с правом публикации)
- `TELEGRAM_CHAT_ID` — личный chat_id для команд (узнать командой `/id` в чате с ботом)
- `ANTHROPIC_API_KEY` — опционально, для LLM-анализа монет

`.env` не коммитится (см. `.gitignore`) — там живёт настоящий токен бота.

## Запуск вручную

```bash
python memebot.py            # боевой режим
python memebot.py --once     # один скан и выход
python memebot.py --dry      # без отправки в Telegram, всё в консоль
```

## Анализ на rug pull

Для монет, близких к порогу алерта, бот дополнительно гоняет проверку контракта:

- **Solana** — [RugCheck](https://rugcheck.xyz): mint/freeze authority, блокировка LP, общий risk score
- **EVM-сети** (ethereum/base/bsc/arbitrum/polygon/avalanche/optimism):
  - [honeypot.is](https://honeypot.is) — можно ли вообще продать токен, налоги на покупку/продажу
  - [GoPlus Security](https://gopluslabs.io) — скрытый/восстанавливаемый овнер, право доминтить токены,
    пауза переводов, чёрные списки, неверифицированный код, концентрация у топ-холдеров, доля овнера/создателя,
    процент заблокированного LP
- Свои эвристики по истории сканов — резкое падение ликвидности (слив LP), объём ≫ ликвидности (wash-трейдинг),
  почти нет продаж (боты), сброс цены после пампа, отсутствие соцсетей

Всё это снижает итоговый скор монеты (`multiplier` в анализе) и попадает в список ⚠️ Риски в тексте алерта —
чем их больше и чем они серьёзнее, тем ниже итоговый score, и явные red flags (honeypot, LP слив) почти обнуляют его.

## Команды бота (memebot.py)

`/scan`, `/top [часы]`, `/stats [часы]`, `/status`, `/threshold [0-100]`, `/mute [минуты]`, `/unmute`, `/news`, `/id`, `/help`

## Соц-скам-сканер (socialbot.py)

Ищет упоминания монет в Telegram и на YouTube по списку фраз-маркеров скам-рекламы
(«100x gem», «guaranteed profit», «гарантированная прибыль», «закрытая группа сигналов» и т.д.,
список — в `CONFIG["keywords"]` внутри файла), вытаскивает из найденных сообщений тикеры
(`$TICKER`) и адреса контрактов, сопоставляет с DexScreener и прогоняет через те же
rug-pull проверки, что и `memebot.py` (RugCheck / honeypot.is / GoPlus), плюс ищет
классические фразы-маркеры прямо в рекламном тексте и просит LLM оценить вероятность скама.

### Настройка — быстрый старт без ключей и логина

```bash
pip install -r requirements.txt
cp .env.example .env
nano .env   # впиши TELEGRAM_BOT_TOKEN, TELEGRAM_CHANNEL_ID/TELEGRAM_CHAT_ID (те же, что у memebot.py)
```

YouTube ищет через `yt-dlp` без ключа автоматически. Для Telegram без логина открой
`socialbot.py`, найди `CONFIG["telegram_search"]["public_channels"]` и впиши туда список
username каналов, которые хочешь мониторить (без `@`), например:

```python
"public_channels": ["somecryptochannel", "anothercallschannel"],
```

Дальше просто:
```bash
python socialbot.py --once --dry     # проверить без реальной отправки
python socialbot.py                  # боевой режим
```

**Ограничение этого режима**: у Telegram нет публичной страницы поиска по всему сервису
(в отличие от YouTube) — без логина бот может читать только конкретные каналы, которые ты
сам укажешь, а не искать по ключевым словам по всему Telegram.

### Поиск по всему Telegram (опционально, нужен логин)

Если хочется не список каналов, а глобальный поиск по ключевым словам по всему Telegram
(как поиск в приложении) — можно подключить юзер-клиент (Telethon). Официальный Bot API
для этого не подходит, читает только каналы, куда бота добавили админом. Рекомендуется
завести под это отдельный (не основной) аккаунт — автоматизированный поиск через личный
профиль формально нарушает разумные лимиты Telegram и в теории может привести к ограничениям.

1. Получи `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` на [my.telegram.org](https://my.telegram.org)
   → API development tools → создать приложение. Впиши в `.env`.
2. Разовая авторизация (спросит номер телефона и код из SMS/Telegram):
   ```bash
   python socialbot.py --login
   ```
   Сессия сохранится в `data/socialbot_session.session` — повторно логиниться не нужно.
3. Как только `TELEGRAM_API_ID`/`TELEGRAM_API_HASH` заданы в `.env`, бот сам переключится
   на этот режим при следующем запуске (`public_channels` в этом случае игнорируется).

Так же и с YouTube: `YOUTUBE_API_KEY` (опционально, [Google Cloud Console](https://console.cloud.google.com)
→ включить YouTube Data API v3 → создать API key) — с ним поиск идёт через официальный API
(быстрее и стабильнее), без него — через `yt-dlp`.

`ANTHROPIC_API_KEY` — опционально, для LLM-вердикта по вероятности скама.

Отказ от ответственности: инструмент фильтрации информации, не финансовый совет.
