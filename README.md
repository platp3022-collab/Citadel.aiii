# Citadel.aiii — Мем-коин сканер + маркетинг-панель

Telegram-бот из двух половин:

- **Сканер** (`memebot.py`) — DexScreener + новостной анализ + алерты в канал/чат.
- **Web3 Marketing Engine** (`marketing.py`) — инфоповод → готовый контент-пак
  (TG-пост, твит, тред, raid-скрипты, вовлечение в чат, промты для картинок)
  с превью и кнопками публикации прямо в Telegram.

## Быстрый запуск (без консоли)

1. Windows — дважды кликни `run.bat`. Mac/Linux — дважды кликни `run.sh`
   (либо `chmod +x run.sh && ./run.sh` в терминале, если двойной клик не запускает).
2. При первом запуске откроется мастер: спросит токен от @BotFather, сам поймает твой
   `chat_id` (просто напиши боту в личку), проверит права в канале, спросит ключи и
   паспорт монеты — и запустит бота. Отдельно его можно вызвать так:

   ```bash
   python setup.py
   ```

3. Оставь открытым это окно/терминал — пока бот работает, он сканирует рынок и присылает алерты в Telegram.
   Закроешь окно — бот остановится.

Бот должен работать именно на твоём компьютере (или сервере) — он не может жить в чужом облаке без твоего участия,
и для алертов ему нужен непрерывно работающий процесс.

## Установка вручную

```bash
pip install -r requirements.txt
```

## Настройка вручную

Если мастер не подошёл — скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHANNEL_ID` — канал для алертов (бота нужно добавить туда админом с правом публикации)
- `TELEGRAM_CHAT_ID` — личный chat_id для команд (узнать командой `/id` в чате с ботом)
- `ANTHROPIC_API_KEY` — LLM-анализ монет и маркетинг-панель (без него панель выключена)
- `OPENAI_API_KEY` — опционально: картинки по промтам и расшифровка голосовых инфоповодов
- `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET` — опционально,
  автопостинг в X (нужен доступ Read and write в developer.x.com)

`.env` не коммитится (см. `.gitignore`) — там живёт настоящий токен бота.

## Запуск вручную

```bash
python memebot.py            # боевой режим
python memebot.py --once     # один скан и выход
python memebot.py --dry      # без отправки в Telegram, всё в консоль
```

## Анализ на rug pull

Для монет, близких к порогу алерта, бот дополнительно гоняет проверку контракта:

- **Solana** — [RugCheck](https://rugcheck.xyz): mint/freeze authority, блокировка LP, общий risk score
- **EVM-сети** (ethereum/base/bsc/arbitrum/polygon/avalanche/optimism):
  - [honeypot.is](https://honeypot.is) — можно ли вообще продать токен, налоги на покупку/продажу
  - [GoPlus Security](https://gopluslabs.io) — скрытый/восстанавливаемый овнер, право доминтить токены,
    пауза переводов, чёрные списки, неверифицированный код, концентрация у топ-холдеров, доля овнера/создателя,
    процент заблокированного LP
- Свои эвристики по истории сканов — резкое падение ликвидности (слив LP), объём ≫ ликвидности (wash-трейдинг),
  почти нет продаж (боты), сброс цены после пампа, отсутствие соцсетей

Всё это снижает итоговый скор монеты (`multiplier` в анализе) и попадает в список ⚠️ Риски в тексте алерта —
чем их больше и чем они серьёзнее, тем ниже итоговый score, и явные red flags (honeypot, LP слив) почти обнуляют его.

## Маркетинг-панель

Бот работает как приватный контент-штаб проекта: ты кидаешь инфоповод — он возвращает
пак и публикует его по нажатию кнопки.

### Паспорт проекта

```bash
cp marketing.example.json marketing.json
```

Заполни все поля (`marketing.json` не коммитится). Пока в файле остаются плейсхолдеры вида
`[Вставьте CA]`, панель генерирует черновики, но **кнопки публикации заблокированы** —
чтобы в канал не улетел пост с плейсхолдером вместо адреса контракта. Посмотреть, чего не
хватает, и дозаполнить можно прямо из чата:

```
/passport                       — что заполнено, чего нет
/passport set ticker $DKING     — записать поле в marketing.json
/passport reload                — перечитать файл с диска
```

### Как пользоваться

1. Пишешь боту в личку инфоповод: `Мы сожгли 3% сапплая`, ссылку, голосовое или .txt-файл
   (голосовые расшифровываются, если задан `OPENAI_API_KEY`). Или явно: `/mkt текст`.
2. Бот присылает превью пака из шести блоков:
   TG-пост · вирусный твит · тред 1/4–4/4 · raid-скрипты · вовлечение в чат · промты для картинок.
   Сразу подсвечивает проблемы: твит длиннее 280 символов, блок не распознан и т.п.
3. Жмёшь кнопку:
   - `🚀 Опубликовать в TG` — постит блок 1 в канал проекта из паспорта;
   - `🐦 Твит в X` / `🧵 Тред в X` — Twitter API v2, тред уходит цепочкой ответов;
   - `🎨 Мем` / `🖼 Баннер` — рисует по промту из пака (gpt-image-1) и присылает в чат;
   - `🔄 Перегенерировать` — другой заход по тому же инфоповоду.

Черновики лежат в той же SQLite-базе, список — `/drafts`. Повторно опубликовать один и тот же
пак в канал бот не даст.

Публикация возможна только из админ-чата (`TELEGRAM_CHAT_ID`), только по нажатию кнопки и
только в ресурсы проекта из паспорта. Массовой рассылки и постинга от чужих аккаунтов в боте нет:
raid-скрипты — это текст для живых участников комьюнити, который они копируют себе сами.

### Без Telegram

```bash
python marketing.py "Мы сожгли 3% сапплая"
```

Печатает готовый пак в консоль — удобно проверить паспорт и tone of voice.

### Настройки

Секция `marketing` в `CONFIG` (`memebot.py`): `enabled`, `model` (по умолчанию `claude-opus-5`,
переопределяется переменной `MARKETING_MODEL`), `passport_path`, `auto_brief` — ловить ли любой
текст в админ-чате как инфоповод (`/mkt_on` · `/mkt_off` переключают на лету).

## Команды бота

Сканер: `/scan`, `/top [часы]`, `/stats [часы]`, `/status`, `/threshold [0-100]`, `/mute [минуты]`, `/unmute`, `/news`, `/id`, `/help`

Маркетинг: `/mkt [инфоповод]`, `/mkt_on`, `/mkt_off`, `/passport`, `/drafts`

Отказ от ответственности: инструмент фильтрации информации и маркетинговой рутины, не финансовый совет. Сгенерированный контент перед публикацией читает человек — за факты в постах отвечает тот, кто нажимает кнопку.
