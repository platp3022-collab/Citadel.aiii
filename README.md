# Citadel.aiii

Два бота в одном репозитории:

| Бот | Что делает | Запуск |
|---|---|---|
| **Мем-коин сканер** (`memebot.py`) | DexScreener + новости + проверка на rug pull, алерты в Telegram | `python memebot.py` |
| **Citadel Trader** (`tradebot.py`) | спот-бот на бирже: сам выводит себе стратегию генетическим поиском, торгует по ней и выгружает её в TradingView | `python tradebot.py trade` |
| **Citadel DEX** (`dexbot.py`) | тот же бот на DEX: сам подбирает пары через DexScreener и торгует свопами через Jupiter | `python dexbot.py trade` |

Инструкции: **[TRADER.md](TRADER.md)** — биржевой бот, **[DEX.md](DEX.md)** — DEX-версия.

## Страница состояния — без сервера и без запуска

Самый простой способ смотреть за ботом: он собирает **один HTML-файл**, который
открывается двойным кликом. Ни Python, ни сервера, ни интернета для просмотра
не нужно — внутри уже всё.

```bash
python tradebot.py dashboard --open     # биржевой бот
python dexbot.py dashboard --open       # DEX
```

Файл ложится в `data/dashboard.html` (`--out` задаёт другой путь), `--open`
сразу открывает его в Microsoft Edge. Дальше можно просто держать вкладку и
жать F5 — или закрепить файл на панели задач.

Что на странице: эквити, свободные средства, P&L, открытые позиции, кривая
счёта, стратегии человеческим языком с метриками валидации, **графики цены с
метками сделок** (▲ покупка, ▼ продажа) и полный журнал сделок.

Чтобы страница обновлялась сама, пока бот торгует:

```bash
python tradebot.py trade --dashboard
```

Бот будет переписывать файл раз в минуту, а сама страница перезагружается раз в
30 секунд — открытая вкладка всегда показывает свежие данные.

## Панель управления в браузере

Не хочешь возиться с командами — запусти панель, она сама откроет Microsoft Edge
(или браузер по умолчанию):

```bash
python webui.py
```

Windows — двойной клик по `run-web.bat`, Mac/Linux — `run-web.sh`.

Что в панели:

- **живые цены**: панель сама опрашивает рынок (биржу через ccxt, DEX через
  DexScreener) раз в несколько секунд и рисует цену в реальном времени — как в
  терминале. Работает, даже когда торговый цикл не запущен. Селектор справа
  переключает режим **«живая цена»** — тиковая лента за последние минуты, с
  линиями входа, стопа и тейка;
- **график входов и выходов**: ▲ покупка, ▼ продажа (бирюзовая — в плюс,
  красная — в минус), пунктир между ними — путь сделки; открытая позиция
  подсвечена, рядом живая цена и текущий процент. Видно прямо по ходу, даже на
  бумажном счёте. Вкладки сверху переключают пары, наведение на метку
  показывает время, цену, объём и причину выхода;
- переключатель **Биржа / DEX** и кнопки всех команд — скачать историю, найти
  стратегию, бэктест, выгрузить в TradingView, отчёт, торговать;
- **терминал прямо в странице**: вывод бота течёт построчно, как в консоли;
- эквити, свободные средства, P&L, открытые позиции, график счёта;
- найденные стратегии человеческим языком и метрики их валидации;
- таблица сделок со ссылками на графики пар и транзакции;
- поля основных настроек (пары, таймфрейм, лимиты риска, параметры поиска).

Панель слушает только `127.0.0.1` и требует токен, который печатается при
запуске, — снаружи к ней не подключиться. Кнопка реальной торговли по умолчанию
выключена; включается явно: `python webui.py --allow-live`.

```bash
python webui.py --mode dex          # сразу в режиме DEX
python webui.py --price-interval 2  # опрашивать цену раз в 2 секунды
python webui.py --no-live-prices    # не опрашивать цены самому
python webui.py --port 8766         # если порт занят
python webui.py --no-browser        # просто поднять сервер и напечатать адрес
```

Опрос цен экономный: биржевые тикеры берутся одним запросом на все пары,
DEX-пулы — одним запросом на сеть. При интервале 4 секунды и шести парах это
15 запросов в минуту, лимиты DexScreener (300/мин) и биржи не задеваются.

Панель ничего не считает сама — она запускает те же `tradebot.py` и `dexbot.py`
и читает их базу, поэтому её можно открывать параллельно с уже работающим ботом.

## Мем-коин сканер

Telegram-бот: DexScreener + новостной анализ + алерты в канал/чат. Логика целиком в `memebot.py`.

## Быстрый запуск (без консоли)

1. Скопируй `.env.example` в `.env` и впиши туда токен и id (см. раздел «Настройка» ниже).
2. Windows — дважды кликни `run.bat`. Mac/Linux — дважды кликни `run.sh`
   (либо `chmod +x run.sh && ./run.sh` в терминале, если двойной клик не запускает).
3. Оставь открытым это окно/терминал — пока бот работает, он сканирует рынок и присылает алерты в Telegram.
   Закроешь окно — бот остановится.

Бот должен работать именно на твоём компьютере (или сервере) — он не может жить в чужом облаке без твоего участия,
и для алертов ему нужен непрерывно работающий процесс.

## Установка вручную

```bash
pip install -r requirements.txt
```

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `TELEGRAM_CHANNEL_ID` — канал для алертов (бота нужно добавить туда админом с правом публикации)
- `TELEGRAM_CHAT_ID` — личный chat_id для команд (узнать командой `/id` в чате с ботом)
- `ANTHROPIC_API_KEY` — опционально, для LLM-анализа монет

`.env` не коммитится (см. `.gitignore`) — там живёт настоящий токен бота.

## Запуск вручную

```bash
python memebot.py            # боевой режим
python memebot.py --once     # один скан и выход
python memebot.py --dry      # без отправки в Telegram, всё в консоль
```

## Анализ на rug pull

Для монет, близких к порогу алерта, бот дополнительно гоняет проверку контракта:

- **Solana** — [RugCheck](https://rugcheck.xyz): mint/freeze authority, блокировка LP, общий risk score
- **EVM-сети** (ethereum/base/bsc/arbitrum/polygon/avalanche/optimism):
  - [honeypot.is](https://honeypot.is) — можно ли вообще продать токен, налоги на покупку/продажу
  - [GoPlus Security](https://gopluslabs.io) — скрытый/восстанавливаемый овнер, право доминтить токены,
    пауза переводов, чёрные списки, неверифицированный код, концентрация у топ-холдеров, доля овнера/создателя,
    процент заблокированного LP
- Свои эвристики по истории сканов — резкое падение ликвидности (слив LP), объём ≫ ликвидности (wash-трейдинг),
  почти нет продаж (боты), сброс цены после пампа, отсутствие соцсетей

Всё это снижает итоговый скор монеты (`multiplier` в анализе) и попадает в список ⚠️ Риски в тексте алерта —
чем их больше и чем они серьёзнее, тем ниже итоговый score, и явные red flags (honeypot, LP слив) почти обнуляют его.

## Команды бота

`/scan`, `/top [часы]`, `/stats [часы]`, `/status`, `/threshold [0-100]`, `/mute [минуты]`, `/unmute`, `/news`, `/id`, `/help`
