# Citadel Trader — спот-бот, который сам придумывает себе стратегию

Бот берёт историю пары с биржи, **генетическим поиском выводит торговую стратегию**,
проверяет её на данных, которых поиск не видел, и торгует по лучшей найденной —
сначала на бумажном счёте, а по твоей команде и реальными ордерами.
Раз в сутки (настраивается) он ищет стратегию заново и меняет активную, если новая
объективно лучше.

Спот — значит **только лонг**: бот покупает и продаёт, шортов и плеча нет.

---

## Быстрый старт

```bash
pip install -r requirements.txt

python tradebot.py fetch                 # скачать историю свечей в кэш
python tradebot.py evolve                # найти стратегию по каждой паре
python tradebot.py backtest --trades     # посмотреть, как она отработала на истории
python tradebot.py trade                 # торговать на бумажном счёте (реальные деньги не тратятся)
```

Или просто запусти `run-trader.sh` (Mac/Linux) / `run-trader.bat` (Windows) — он сделает
все три шага сам.

Реальная торговля — отдельной командой, с подтверждением и ключами биржи в `.env`:

```bash
python tradebot.py trade --live
```

## Как бот придумывает стратегию

1. **Сигнальная сетка.** Из свечей считаются индикаторы (EMA, RSI, MACD, ADX, ATR,
   Боллинджер, каналы Дончиана, импульс, объём, волатильность), из них — ~40 булевых
   условий вида «EMA21 выше EMA50», «пробой максимума 55 баров», «ADX > 25».
2. **Геном стратегии** — это 1–3 условия входа (объединены через И), 0–2 условия выхода
   (через ИЛИ) и параметры риска: стоп в ATR, тейк в ATR, трейлинг, лимит времени в
   позиции, риск на сделку, пауза после выхода.
3. **Генетический алгоритм**: случайная популяция → отбор турниром → скрещивание →
   мутации, 25 поколений. Фитнес считается на обучающем окне, причём отдельно по двум
   его половинам: геном, который зарабатывает только на одном участке, штрафуется.
4. **Валидация.** Лучшие 15 геномов прогоняются по последним 30% истории, которых поиск
   не видел. Побеждает лучший по валидации, и только если он прошёл фильтры:
   положительный результат, profit factor > 1, минимум сделок, просадка в пределах лимита.
5. **Если ничего не прошло — стратегии нет**, и бот по этой паре не торгует. Это
   штатное поведение, а не ошибка: рынок не обязан быть торгуемым.

Фитнес — не «максимальная доходность», а смесь Sharpe и MAR (доход / просадка) со
штрафами за глубокую просадку, за перепиливание счёта комиссиями и за отрицательный
результат.

### Что бот делает, чтобы не обманывать себя

- сигнал считается по **закрытой** свече, вход — по следующей;
- индикаторы на баре `i` не зависят от будущих баров (проверено тестами);
- каналы Дончиана берут максимум **предыдущих** N баров, а не включая текущий;
- в бэктесте списываются комиссия тейкера и проскальзывание;
- если в одном баре задело и стоп, и тейк — считается, что сработал стоп;
- отбор идёт по валидации на невиданных данных, а не по обучающей выборке.

## Команды

| Команда | Что делает |
|---|---|
| `fetch` | скачивает и кэширует свечи в `data/candles/*.csv` |
| `evolve` | ищет стратегию, сохраняет в базу и делает активной |
| `backtest` | прогоняет активную стратегию по истории (`--trades` — список сделок) |
| `trade` | торговый цикл: бумажный счёт по умолчанию, `--live` — реальные ордера |
| `pine` | выгружает стратегию в Pine Script для TradingView |
| `report` | эквити, открытые позиции, активные стратегии, последние сделки |
| `reset` | сбрасывает бумажный счёт, позиции и историю сделок |

Общие флаги: `--symbols BTC/USDT,ETH/USDT`, `--timeframe 4h`, `--exchange bybit`,
`--history 5000`, `--offline` (работать только по кэшу, без сети), `--dry` (не слать
уведомления в Telegram), `-v` (подробный лог).

```bash
python tradebot.py evolve --symbol SOL/USDT --generations 40 --population 120
python tradebot.py backtest --offline --symbols BTC/USDT --trades
python tradebot.py trade --once            # один круг и выход (удобно для cron)
```

## Торговый цикл

Раз в `poll_seconds` (по умолчанию 20 с) бот:

1. подтягивает свечи по парам, где закрылся новый бар, и пересчитывает индикаторы;
2. по текущей цене проверяет открытые позиции — стоп-лосс, тейк-профит, трейлинг;
3. на закрытии бара проверяет сигналы выхода и лимит времени в позиции;
4. на закрытии бара проверяет сигналы входа и, если всё сходится, покупает;
5. раз в `retrain_hours` заново ищет стратегию и меняет активную, если новая лучше
   текущей минимум на `adopt_margin` (10%).

Размер позиции считается от риска: `объём = эквити × risk_pct / (цена − стоп)`,
сверху ограничен долей эквити в одной позиции (`max_position_frac`) и свободным кэшем.

## Защита счёта

| Лимит | По умолчанию | Что делает |
|---|---|---|
| `max_drawdown_stop` | 25% | просадка от пика эквити — бот перестаёт открывать новые позиции |
| `daily_loss_stop` | 8% | дневной убыток — пауза до следующего дня (UTC) |
| `max_positions` | 2 | сколько позиций одновременно |
| `max_position_frac` | 35% | максимум доли счёта в одной позиции |
| стоп-лосс | часть генома | всегда есть, привязан к ATR |

Уже открытые позиции при срабатывании защит доводятся до штатного выхода
(стоп / тейк / сигнал), новые не открываются.

```bash
python tradebot.py dashboard --open
```

Собирает самодостаточный HTML: эквити, позиции, стратегии, графики цены
с метками сделок и журнал. Открывается двойным кликом, сервер не нужен.
Чтобы файл обновлялся во время торговли: `python tradebot.py trade --dashboard`.

## Смотреть стратегию в TradingView

Бот умеет переводить свою стратегию в Pine Script — можно увидеть входы, выходы,
стоп и тейк прямо на графике и прогнать всё через Strategy Tester.

```bash
python tradebot.py pine                     # по всем парам → data/pine/*.pine
python tradebot.py pine --symbol BTC/USDT   # только одна пара
python tradebot.py pine --trades            # ещё и реальные сделки бота на график
```

Дальше в TradingView:

1. открой график той же пары и того же таймфрейма (команда печатает тикер,
   например `BINANCE:BTCUSDT`, 1h);
2. **Pine Editor** внизу экрана → вставь содержимое `.pine` файла → **Add to chart**;
3. вкладка **Strategy Tester** — кривая эквити, просадка, список сделок;
4. параметры риска (стоп, тейк, трейлинг, риск на сделку, время в позиции)
   вынесены в настройки скрипта — их можно крутить прямо на графике и сразу
   видеть результат.

Что видно на графике: треугольники — сигналы входа и выхода, красная линия — стоп,
бирюзовая — тейк, подсветка фона — бот в позиции. Плюс `alert()` на вход и выход:
можно повесить алерт в TradingView и получать сигналы в телефон параллельно с ботом.

С флагом `--trades` рядом создаётся второй скрипт — индикатор-оверлей с
**реальными сделками бота** из его базы (метки «куп/прод» с ценой и P&L).
Ставь его на тот же график поверх стратегии, чтобы сверить, что бот наторговал
на самом деле, с тем, что показывает бэктест.

**Цифры в Strategy Tester не совпадут с бэктестом бота один в один:** у TradingView
свои данные по свечам, там нет проскальзывания из конфига бота, а размер позиции
считается от эквити скрипта. Совпадать должна логика входов и выходов, а не
доходность до второго знака.

## Настройка

Всё лежит в `citadel/config.py` — правь прямо там или переопределяй через `.env`
переменными с префиксом `CITADEL_`:

```bash
CITADEL_SYMBOLS=BTC/USDT,ETH/USDT
CITADEL_TIMEFRAME=4h
CITADEL_START_BALANCE=1000
CITADEL_MAX_POSITIONS=2
CITADEL_RETRAIN_HOURS=12
CITADEL_LOG_LEVEL=INFO
```

Реальная торговля через `.env` **не включается** — только явным флагом `--live`,
чтобы случайная переменная окружения не начала тратить деньги.

Уведомления о сделках и смене стратегии уходят в Telegram, если в `.env` есть
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (те же, что у мем-коин сканера).

### Реальная торговля

1. Создай на бирже API-ключ **только со спотовой торговлей**; вывод средств — запретить.
   По возможности привяжи ключ к IP сервера.
2. Впиши `EXCHANGE_API_KEY` и `EXCHANGE_API_SECRET` в `.env`.
3. Прогоняй бота на бумаге хотя бы пару недель и смотри `python tradebot.py report`.
4. Только потом — `python tradebot.py trade --live` (бот попросит подтверждение;
   `--yes` пропускает вопрос, для systemd/докера).

Ордера — рыночные, поэтому реальная цена исполнения может отличаться от расчётной;
в бэктесте это учтено проскальзыванием, но на неликвидных парах разница будет больше.

## Круглосуточная работа

systemd:

```bash
sudo cp deploy/trader.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now trader
journalctl -u trader -f
```

Docker:

```bash
docker build -t citadel .
docker run -d --name trader --env-file .env -v "$PWD/data:/app/data" citadel python tradebot.py trade
```

## Честные ограничения

- **Прибыльный бэктест ничего не гарантирует.** Поиск по сотням комбинаций сам по себе
  подгоняет результат под историю; валидация на невиданных данных это лишь ограничивает.
- Только лонг и только споты: на падающем рынке лучшее, что делает бот, — сидит в кэше.
- Одна валидационная выборка, а не полноценный walk-forward по многим окнам.
- Рыночные ордера, комиссия тейкера; на низкой ликвидности проскальзывание съест край.
- Комиссия считается в котируемой валюте; если биржа берёт её в BNB/базовом активе,
  учёт P&L будет чуть отличаться от выписки.
- Бот не знает про новости, форки, делистинги и остановки торгов.

Это инструмент, а не финансовый совет. Торгуй только теми деньгами, которые готов потерять.
