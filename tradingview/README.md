# Bubble — тепловая карта точек входа для TradingView

Индикатор на Pine Script v5: `bubble_heatmap.pine`.

Рисует пузыри прямо на графике. Цвет пузыря = насколько интересен момент:

| Цвет | Что значит | Что делать |
|---|---|---|
| **синий** | объёма нет, рынок спит | ничего интересного, пропускаем |
| **оранжевый** | объём пришёл, но покупки и продажи 50/50 | баланс, направление не выбрано — ждём |
| **красный** | много объёма **и** одна сторона явно давит | точка входа — под баром треугольник на покупки, над баром на продажи |

Между ними цвет переходит плавно, так что видно и промежуточные состояния.
Размер пузыря растёт вместе с теплом: мелкая точка — фон, крупный круг — событие.

## Как поставить

1. TradingView → внизу вкладка **Pine Editor**.
2. **Open → New indicator**, выдели весь шаблон и удали.
3. Вставь содержимое `bubble_heatmap.pine` целиком.
4. **Save** (имя, например `Bubble`) → **Add to chart**.

## Как считается тепло

Реального ордер-флоу в Pine нет — TradingView отдаёт только OHLCV. Поэтому объём делится
между покупателями и продавцами по форме свечи, это стандартный приём.

```
тепло = АКТИВНОСТЬ * (0.5 + 0.5 * ПЕРЕВЕС)
```

* **АКТИВНОСТЬ** (0…1) — насколько объём бара выделяется на фоне последних N баров
  (перцентиль объёма, плюс размах бара, если включена волатильность).
* **ПЕРЕВЕС** (0…1) — насколько за окно дельты покупки перевесили продажи:
  сумма (покупки − продажи), делённая на сумму объёма.

Отсюда ровно та шкала, которая нужна:

* активности нет → тепло 0 → синий;
* активность есть, стороны равны → тепло 0.5 → оранжевый;
* активность есть и одна сторона давит → тепло 1 → красный.

Модель деления объёма выбирается в настройках:

* **Позиция закрытия** — `покупки = объём * (close − low) / (high − low)`.
* **Тиковое правило** — весь объём бара уходит в сторону движения цены.
* **Смешанная** — среднее двух, стоит по умолчанию.

## Алерты

Правый клик по графику → **Add alert** → Condition: `Bubble`:

* `Точка входа покупки`
* `Точка входа продажи`
* `Красная зона`
* `Оранжевая зона 50 на 50`

## Цифры под курсором

Точные значения видны в **Data Window** (правая панель, иконка со стрелками):
Тепло %, Активность %, Перевес %, Покупки %, Дельта.

## Настройка под инструмент

| Хочу | Крути |
|---|---|
| чаще сигналы | ниже «Порог красного», ниже «Мин. перевес для сигнала» |
| меньше шума | выше «Порог красного», выше «Сглаживание тепла» |
| реакция быстрее | ниже «Окно активности», ниже «Окно дельты» |
| низколиквидная монета | «Окно активности» 30–50 |
| ликвидная пара (BTC, ETH) | «Окно активности» 100–200, «Окно дельты» 20–30 |

## Ограничения — читать обязательно

* Индикатор видит только объём с той биржи и пары, на которой открыт график. На мем-коинах
  через DEX-графики объём часто рваный и с ботовыми вошами — тепло будет врать.
* Деление на покупки и продажи — оценка по свече, а не настоящая лента. Ошибается на барах
  с длинными фитилями и на гэпах.
* Красный пузырь означает «здесь произошло много и однонаправленно», а не готовый сигнал.
  Это фильтр к твоей системе (уровни, тренд, стоп), а не замена ей.
