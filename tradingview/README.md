# Bubble — тепловая карта точек входа для TradingView

Индикатор на Pine Script v6: `bubble_heatmap.pine`.

Показывает пузыри-«тепло» прямо на графике. Цвет пузыря = насколько интересен момент:

| Цвет | Что значит | Что делать |
|---|---|---|
| 🔵 **синий** | объёма нет, рынок спит | ничего интересного, пропускаем |
| 🩵 голубой | начинает оживать | смотрим, но рано |
| 🟠 **оранжевый** | объём пришёл, но покупки и продажи **50/50** | баланс, борьба, направление не выбрано — ждём |
| 🟥 тёпло-красный | объём + перевес одной стороны | зона формируется |
| 🔴 **красный** | много объёма **и** одна сторона явно давит | **точка входа** — треугольник под баром (покупки) или над баром (продажи) |

Размер пузыря тоже растёт вместе с теплом: мелкая точка — фон, крупный шар — событие.

## Как поставить

1. Открой TradingView → внизу вкладка **Pine Editor**.
2. **Open → New indicator**, выдели весь шаблон и удали.
3. Скопируй туда содержимое `bubble_heatmap.pine` целиком.
4. **Save** (дай имя, например `Bubble`) → **Add to chart**.
5. Дальше индикатор живёт в списке «Мои скрипты» / Indicators → Favorites.

## Как считается тепло

Реального ордер-флоу (кто покупал, кто продавал) в Pine нет — TradingView отдаёт только OHLCV.
Поэтому объём делится между сторонами по форме свечи, это стандартный приём:

```
тепло = АКТИВНОСТЬ × (0.5 + 0.5 × ПЕРЕВЕС)
```

* **АКТИВНОСТЬ** (0…1) — насколько объём этого бара выделяется на фоне последних `N` баров
  (перцентиль объёма, опционально с добавкой размаха бара — объём без движения цены весит меньше).
* **ПЕРЕВЕС** (0…1) — насколько за окно дельты покупки перевесили продажи:
  `|Σ(buyVol − sellVol)| / Σvolume`, отнормированный порогом насыщения.

Отсюда ровно та шкала, которая нужна:

* активности нет → тепло ≈ 0 → **синий**;
* активность есть, стороны равны → тепло ≈ 0.5 → **оранжевый (50/50)**;
* активность есть и одна сторона давит → тепло → 1 → **красный (точка входа)**.

Модель деления объёма выбирается в настройках:

* **Позиция закрытия** — `buy = vol × (close − low) / (high − low)`. Классика (Better Volume).
* **Тиковое правило** — весь объём бара уходит в сторону движения цены.
* **Смешанная** — среднее двух, самый устойчивый вариант.

## Тепловая карта уровней

Отдельный блок настроек рисует профиль объёма как настоящий heatmap: диапазон за последние
`vpLen` баров режется на `vpRows` уровней, каждый закрашивается по тому же правилу
(много объёма + перевес = краснее и плотнее). Пунктирная линия — **POC**, уровень с максимальным
объёмом. Это те цены, куда рынок возвращается и где стоят реальные заявки.

## Алерты

Правый клик по графику → **Add alert** → Condition: `Bubble`, дальше на выбор:

* `🔴 Точка входа — покупки`
* `🔴 Точка входа — продажи`
* `🔴 Красная зона (любая сторона)`
* `🟠 Оранжевая зона 50/50`

## Настройка под инструмент

| Хочу | Крути |
|---|---|
| больше красного / чаще сигналы | ↓ «Порог красного», ↓ «Мин. перевес для сигнала» |
| меньше шума | ↑ «Порог красного», ↑ «Сглаживание тепла», ↑ «Не рисовать пузырь ниже тепла» |
| реакция быстрее | ↓ «Окно активности», ↓ «Окно дельты» |
| низколиквидная монета | «Окно активности» 30–50, модель потока «Смешанная» |
| ликвидная пара (BTC, ETH) | «Окно активности» 100–200, «Окно дельты» 20–30 |

## Ограничения — читать обязательно

* Индикатор видит **только объём с той биржи/пары, на которой открыт график**. На мем-коинах
  через DEX-графики объём часто рваный и с ботовыми вошами — тепло будет врать.
* Деление на покупки/продажи — **оценка по свече**, а не настоящая лента. Ошибается на барах
  с длинными фитилями и на гэпах.
* Пузырь рисуется по **закрытому бару** (без перерисовки). На текущем незакрытом баре пузыря нет —
  это осознанно: иначе он мигал бы туда-сюда и врал бы в бэктесте.
* Красный пузырь — это «здесь произошло много и однонаправленно», а не готовый сигнал на вход.
  Работает как фильтр к твоей системе (уровни, тренд, стоп), а не вместо неё.
