Страница открыта не с диска

Похоже, файл открыт через сервер с ограничительной политикой. Запросы к бирже и к API могут блокироваться. Скачайте screener.html и откройте двойным кликом — так работает без ограничений.

Ключ API и настройки

Хранится только в localStorage вашего браузера и уходит единственным адресом — на api.anthropic.com. Ключ можно получить на console.anthropic.com → Settings → API Keys.

Данные

По одной в строке. Дневные свечи берутся с публичного API Binance — он открыт для браузера, ключ для него не нужен. Акции сюда не подходят: Yahoo и большинство брокеров запрещают запросы со страниц, поэтому для них есть вкладка CSV.

Колонки в любом порядке, разделитель — запятая, точка с запятой или табуляция. Несколько инструментов в одном файле различаются колонкой ticker. Нужно минимум 60 строк на инструмент, а для SMA200 — 200. Выгрузка из TradingView, Investing.com или брокера подойдёт как есть.

Не является инвестиционной рекомендацией. Инструмент фильтрации информации: все уровни и сценарии — гипотезы, а не сигналы.
