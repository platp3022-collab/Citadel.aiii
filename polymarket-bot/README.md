# Polybot — торговый бот для Polymarket

Отдельный проект в этом репозитории: автоматическая торговля на прогнозных рынках Polymarket
с терминальным дашбордом. Три стратегии (RSI+VWAP, CVD-дивергенция, возврат к среднему),
риск-менеджер, бумажное исполнение по реальному стакану и боевой режим через CLOB.
Вся логика в `polybot.py`, самопроверка — в `selftest.py`.

Управлять можно двумя способами: **из терминала** (`polybot.py`) или **из Telegram**
(`tgapp.py` — бот с командами плюс Mini App, панель открывается прямо внутри мессенджера).
Движок в обоих случаях один и тот же.

## Быстрый запуск — одна команда

```bash
python start.py
```

`start.py` сам поставит зависимости, создаст `.env`, спросит токен бота (один раз, потом
запомнит) и запустит его. Токен можно передать сразу: `python start.py 123456789:AAH...`.
Без Telegram, просто дашборд в терминале — `python start.py --terminal`.

Если антивирус или SmartScreen ругается на `.bat`/`.sh` — это нормально для скриптов
запуска, просто пользуйся `start.py`: то же самое, но обычным Python.

Альтернатива для тех, у кого `.bat` работает: `run.bat` / `run.sh` (терминальный режим),
`run-tg.bat` / `run-tg.sh` (Telegram). Оставь окно открытым — закроешь, бот остановится.

## Установка вручную

```bash
pip install -r requirements.txt
cp .env.example .env
python polybot.py
```

## Режимы

```bash
python start.py                 # всё сразу: зависимости, .env, токен, запуск
python polybot.py               # бумажная торговля по реальным котировкам + дашборд
python polybot.py --once        # один цикл сканирования и выход
python polybot.py --no-ui       # без дашборда, обычные логи (для сервера)
python polybot.py --backtest 7d # прогон по истории цен: 1d, 7d, 30d, max
python polybot.py --bankroll 500
python polybot.py --live        # реальные ордера (см. ниже)
python tgapp.py                 # управление из Telegram: бот + Mini App
python tgapp.py --no-web        # только команды бота, без Mini App
python selftest.py              # проверка кода на синтетическом рынке, сеть не нужна
```

## Telegram: бот и Mini App

Движок крутится у тебя на компьютере или сервере, Telegram — пульт и витрина.

**Настройка за три шага:**

1. Создай бота у [@BotFather](https://t.me/BotFather) → получишь токен.
2. Запусти `python start.py` и вставь токен, когда спросит (или сразу
   `python start.py <токен>`). Он сохранится в `.env`, дальше запуск без вопросов.
3. Напиши боту `/start` — первый написавший становится владельцем, бот его запомнит.
   `chat_id` искать не нужно; если хочешь закрепить жёстко — пропиши `TELEGRAM_CHAT_ID`.

Токен живёт только в `.env` на твоём компьютере: этот файл в `.gitignore` и в репозиторий
не уезжает. Держать токен в коде публичного репозитория нельзя — его находят автоматические
сканеры за минуты, и бота уводят.

**Команды:** `/pnl` — сколько сейчас в плюсе (за всё время, за сегодня, по стратегиям,
лучшая и худшая позиция) — это быстрый ответ, без захода в Mini App; `/panel` — живая панель,
она сама обновляется; `/status`, `/positions`, `/trades`, `/stats`, `/pause` (не открывать
новое), `/resume`, `/flat` (закрыть всё). О каждом входе и выходе бот пишет сам,
о срабатывании риск-стопа — тоже.

```
💰 В плюсе на +$43.20
эквити $1,043.20 из $1,000.00 (+4.32%)

🟢 сегодня +$12.50
✅ реализовано +$31.10
⏳ в открытых позициях +$12.10
💵 свободно $820.00 · в рынке $223.20
```

**Mini App** — та самая «панель внутри Telegram»: позиции с плавающим P&L, кривая эквити,
метрики, кнопки паузы, закрытия отдельной позиции и закрытия всего. Telegram открывает
Mini App только по **https**, поэтому нужен публичный адрес:

- на сервере — домен и сертификат (nginx или caddy перед портом `8080`);
- на домашнем компьютере — туннель: `cloudflared tunnel --url http://localhost:8080`,
  выданный `https://…` вписать в `WEBAPP_PUBLIC_URL`.

Без `WEBAPP_PUBLIC_URL` бот работает как обычный бот — просто без кнопки панели.

**Доступ.** Управляет только владелец — тот, кто первым написал `/start` (или указанный
в `TELEGRAM_CHAT_ID`); всем остальным бот отвечает отказом.
Запросы из Mini App проверяются по подписи `initData` (HMAC с токеном бота) и по id
пользователя, так что знания адреса панели недостаточно — деньгами она управляет,
и открыта только владельцу.

## Как он торгует

1. **Вселенная.** Gamma API отдаёт активные рынки; остаются те, у кого есть стакан,
   ликвидность выше `MIN_LIQUIDITY`, оборот выше `MIN_VOLUME_24H`, спред уже `MAX_SPREAD`,
   цена в коридоре 0.08–0.92 и до расчёта больше шести часов. Хвосты и «мёртвые» рынки
   отсекаются: там комиссия и спред съедают любой перевес.
2. **Данные.** По каждому рынку качается стакан (CLOB `/book`), история цен
   (`/prices-history`) и лента сделок (Data API `/trades`).
3. **Стратегии.** Каждая возвращает справедливую цену `fair` и уверенность:
   - **RSI + VWAP** — цена ушла от средневзвешенной по ленте, RSI подтверждает истощение;
     ставка на возврат к VWAP.
   - **CVD-дивергенция** — цена переписала минимум, кумулятивная дельта объёма — нет:
     продавец выдохся. Зеркально для максимумов.
   - **Возврат к среднему** — z-score истории цен; чем ближе расчёт рынка, тем выше порог
     входа (у самого дедлайна двигает информация, а не шум).
4. **Перевес.** Сигнал живёт, только если `fair − цена − комиссия ≥ MIN_EDGE`. Иначе он
   не доходит до исполнения.
5. **Размер.** Доля Келли по бинарному исходу, зажатая до четверти Келли, домноженная на
   уверенность и обрезанная лимитами `RISK_PER_TRADE` и `MAX_POSITION_USD`.
6. **Исполнение.** Шортов на Polymarket нет, поэтому сигнал на продажу YES исполняется
   покупкой парного токена NO (цена ≈ 1 − p). В бумажном режиме заявка проходит по реальным
   уровням стакана с проскальзыванием — тонкий стакан просто отменяет вход.
7. **Выход.** Тейк-профит `TAKE_PROFIT`, стоп-лосс `STOP_LOSS`, тайм-стоп `TIME_STOP_MIN`,
   принудительное закрытие за час до расчёта рынка и общий риск-стоп портфеля.

## Риск-менеджмент

- `RISK_PER_TRADE` — потолок на один вход (по умолчанию 2% банка).
- `MAX_POSITIONS` — не больше 6 позиций сразу, по одной на рынок.
- `DAILY_LOSS_LIMIT` — минус 6% за сутки, и бот перестаёт открывать новое.
- `MAX_DRAWDOWN` — минус 20% от пика эквити, и торговля останавливается совсем.
- В дашборде всегда видно win rate, profit factor, максимальную просадку и Sharpe —
  чтобы решение «выключить» принималось по цифрам, а не по ощущениям.

## Дашборд

Один кадр в терминале: панели трёх стратегий с последними сигналами, открытые позиции
с текущим P&L, лента исполнений, кривая эквити и строка метрик. Логи при включённом
дашборде уходят в `data/polybot.log`, чтобы не рвать картинку. Без TTY (сервер, cron)
бот сам переключается в текстовые логи.

История сделок и кривая эквити пишутся в `data/polybot.sqlite3` — перезапуск не теряет статистику.

## Боевой режим

```bash
pip install py-clob-client
```

В `.env`: `POLYBOT_CONFIRM_LIVE=yes`, `POLYMARKET_PRIVATE_KEY` (кошелёк Polygon с USDC),
при необходимости ключи CLOB (`POLYMARKET_API_KEY/SECRET/PASSPHRASE` — без них бот выведет их
из приватного ключа сам) и `POLYMARKET_SIGNATURE_TYPE` (0 — обычный кошелёк, 1 — Polymarket proxy,
2 — Gnosis Safe).

Предохранитель `POLYBOT_CONFIRM_LIVE` стоит специально: без него `--live` не стартует.
Приватный ключ живёт только в `.env`, который не коммитится.

Прежде чем включать боевой режим, погоняй бумажный хотя бы неделю на тех же настройках
и сравни результат с `--backtest`. Если бумага в минусе — боевой режим будет в минусе быстрее.

## Что это не делает

Это исполнитель стратегии, а не генератор дохода. Прогнозные рынки — игра с отрицательной
суммой после спреда и комиссий: у входа ты сразу платишь половину спреда, а маркет-мейкер
на той стороне видит поток лучше тебя. Цифры вроде «+2643$ за ночь» из рекламных постов не
воспроизводит никакой код — они рисуются в фотошопе; всё, что здесь можно честно обещать, —
дисциплина исполнения: фиксированный риск, автоматические стопы и полная запись сделок.
Бэктест по историческим ценам всегда оптимистичнее реальности — в нём нет очереди в стакане,
проскальзывания на тонком рынке и неудачных дней.

По умолчанию бот торгует бумагой. Боевой режим включается руками, своим ключом и на свой риск.
Торгуй только теми деньгами, потерю которых переживёшь.
