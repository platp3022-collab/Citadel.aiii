# Citadel DEX — тот же бот, но на децентрализованных биржах

Движок один и тот же: индикаторы, генетический поиск стратегии, валидация на
невиданных данных, торговый цикл, защиты счёта, экспорт в TradingView.
Меняется только то, откуда берутся данные и как исполняются сделки.

| | Биржа (`tradebot.py`) | DEX (`dexbot.py`) |
|---|---|---|
| Пары | задаёшь руками | подбираются автоматически через DexScreener |
| Свечи | биржа через ccxt | GeckoTerminal (по адресу пула) |
| Цена, ликвидность | биржа | DexScreener |
| Исполнение | ордер на бирже | своп через Jupiter (Solana) |
| Издержки | комиссия тейкера | комиссия пула + влияние на цену + комиссия сети |
| Главный риск | движение цены | пул может остаться без ликвидности |

---

## Про Axiom — важное

**У Axiom нет публичного API для сторонних ботов.** Это веб-терминал: он сам
маршрутизирует свопы через агрегаторы (в первую очередь Jupiter) и не даёт
внешним программам легального способа торговать от твоего имени. Обходные пути
через перехват его внутренних запросов и токенов сессии — это нарушение их
условий и прямой путь к потере доступа и средств, поэтому я такое не делал.

Что сделано вместо этого: бот работает **с теми же токенами, которые ты видишь
в Axiom**, и исполняет свопы через **Jupiter** — тот самый агрегатор, через
который ходит и сам Axiom. Маршрут и цена те же, просто без посредника.
Если хочешь именно интерфейс Axiom — смотри в нём, а торгуй ботом.

## Быстрый старт

```bash
pip install -r requirements.txt

python dexbot.py discover     # подобрать пары: DexScreener + фильтры безопасности
python dexbot.py evolve       # найти стратегию под каждую пару
python dexbot.py backtest     # проверить на истории с реальными издержками пула
python dexbot.py trade        # торговать на бумажном счёте
```

Ключи и кошелёк на этом этапе не нужны: DexScreener и GeckoTerminal —
бесплатные публичные API без регистрации.

## Как бот выбирает, чем торговать

Списка пар нет — он собирается сам, и это отдельная работа, потому что на DEX
листинг не значит ничего: пул создаётся за минуту и осушается за секунду.

1. **Кандидаты** — поиск DexScreener по запросам (`CITADEL_DISCOVER_QUERIES`,
   по умолчанию `SOL,USDC`) плюс продвигаемые токены. Продвижение — это реклама,
   а не знак качества, поэтому дальше все идут через одни и те же фильтры.
2. **Фильтры безопасности** (`citadel/dex/safety.py`) — пара обязана пройти всё:

   | Проверка | По умолчанию | Зачем |
   |---|---|---|
   | ликвидность | ≥ $50 000 | из тонкого пула не выйти без потерь |
   | объём за сутки | ≥ $100 000 | без оборота нет и цены |
   | возраст пула | ≥ 72 ч | свежие пулы — территория рагов |
   | сделок за сутки | ≥ 200 | иначе это не рынок |
   | покупок к продажам | ≤ 5× | «все покупают, никто не продаёт» = honeypot |
   | оборот к ликвидности | 0.15…30× | ниже — пул стоячий, выше — wash-трейдинг |
   | FDV к ликвидности | ≤ 400× | вся капитализация висит на тонком пуле |
   | RugCheck (Solana) | score ≤ 1500 | право доминтить, заморозка, незалоченный LP |

3. **История свечей** — у пула должно быть минимум ~420 свечей выбранного
   таймфрейма, иначе искать стратегию не на чем.
4. Оставшиеся сортируются по глубине и живости пула, берутся первые
   `CITADEL_UNIVERSE_SIZE` (по умолчанию 6). Список пересматривается раз в
   `CITADEL_REDISCOVER_HOURS` (12 ч); пары, в которых есть открытая позиция,
   из работы не выбрасываются.

Посмотреть, кого и почему отсеяло:

```bash
python dexbot.py discover --show-rejected
```

## Честные издержки

На DEX ты торгуешь против пула и сам двигаешь цену. Для пула `x*y=k` при
ликвидности L (обе стороны, значит резерв ≈ L/2) сделка на сумму A сдвигает цену на

```
impact = A / (L/2 + A)
```

Сделка размером в 1% ликвидности пула стоит примерно **2% цены**. Поэтому:

- объём каждой сделки ограничен `CITADEL_MAX_POOL_FRAC` (по умолчанию 1% ликвидности);
- при **поиске стратегии** к базовому проскальзыванию добавляется ожидаемое
  влияние на цену именно этого пула — иначе бэктест систематически врёт в плюс;
- бумажный счёт считает по той же формуле плюс комиссия пула (0.25%) и
  комиссия сети за своп (`CITADEL_PRIORITY_FEE_USD`).

В выводе `backtest` видно, во сколько это обошлось: `издержки 102 bps`.

## Защита от рага

Помимо обычных стоп-лосса, тейка и лимитов счёта, у DEX-версии есть сторож,
который смотрит не на цену, а на пул: **если ликвидность упала больше чем на
`CITADEL_RUG_LIQUIDITY_DROP` (50%) от той, что была на входе, или провалилась
ниже половины минимума — бот выходит немедленно**, не дожидаясь сигналов
стратегии. Перед каждым входом пара заново прогоняется через фильтры: за сутки
она могла испортиться.

Полностью это не спасает. Если ликвидность вынимают одной транзакцией, выйти
не успеет никто — ни бот, ни человек.

## Настройка

```bash
CITADEL_CHAIN=solana                   # solana, base, bsc, ethereum, arbitrum…
CITADEL_TIMEFRAME=15m                  # на DEX история короткая: 5m / 15m / 1h
CITADEL_START_BALANCE=500
CITADEL_UNIVERSE_SIZE=6                # сколько пар держать в работе
CITADEL_MAX_POSITIONS=2
CITADEL_MAX_POOL_FRAC=0.01             # доля ликвидности пула в одной сделке
CITADEL_MIN_LIQUIDITY_USD=50000
CITADEL_MIN_VOLUME_H24_USD=100000
CITADEL_MIN_AGE_HOURS=72
CITADEL_RUGCHECK=true
CITADEL_SLIPPAGE_BPS=100               # базовый допуск, 100 = 1%
CITADEL_PRIORITY_FEE_USD=0.05
```

Хочешь торговать конкретные пулы вместо автоподбора:

```bash
python dexbot.py --symbols solana:8sLbNZ...,solana:Czfq3x... evolve
```

Адрес пула — это то, что в ссылке DexScreener после сети:
`dexscreener.com/solana/<адрес_пула>`.

### Реальные свопы

```bash
pip install solders                    # нужен только для подписи транзакций
```

```bash
SOLANA_PRIVATE_KEY=<base58 приватный ключ отдельного кошелька>
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
```

```bash
python dexbot.py trade --live
```

Правила, которые стоит соблюдать:

1. **Отдельный кошелёк** только под бота, с суммой, которую не жалко потерять.
   Приватный ключ в `.env` = полный доступ к этому кошельку.
2. Держи на нём немного SOL на комиссии — своп без SOL не пройдёт.
3. Публичный RPC (`api.mainnet-beta.solana.com`) душит по лимитам; для боевой
   работы возьми свой (Helius, QuickNode, Triton).
4. Количество после свопа бот берёт **из фактического баланса кошелька**, а не
   из котировки: токены с налогом на перевод доставляют меньше обещанного.

## Команды

| Команда | Что делает |
|---|---|
| `discover` | подбирает пары (`--show-rejected` — показать отсев с причинами) |
| `pairs` | текущий список пар, ликвидность, активные стратегии |
| `fetch` | скачивает свечи в кэш |
| `evolve` | ищет стратегию под каждую пару |
| `backtest` | прогон по истории с издержками конкретного пула (`--trades`) |
| `trade` | торговый цикл (`--live` — реальные свопы, `--once` — один круг) |
| `pine` | выгрузка стратегии в Pine Script |
| `report` | счёт, позиции, стратегии, последние сделки |
| `reset` | сброс бумажного счёта |

Флаги: `--chain`, `--symbols`, `--timeframe`, `--history`, `--offline`, `--dry`, `-v`.

## Что внутри

```
dexbot.py                точка входа
citadel/dex/
  config.py              конфиг DEX (наследует общий)
  http.py                HTTP на stdlib: ретраи, лимит запросов
  dexscreener.py         пары, ликвидность, объёмы, возраст, соцсети
  geckoterminal.py       свечи по адресу пула
  safety.py              фильтры «можно ли это торговать» + RugCheck
  market.py              адаптер под интерфейс биржевого Market
  broker.py              бумажный счёт с влиянием на цену + свопы
  jupiter.py             Jupiter API и JSON-RPC Solana
  bot.py                 подбор пар, сторож ликвидности, торговый цикл
  cli.py                 командная строка
```

Всё остальное — индикаторы, геном, бэктест, поиск, хранилище, Pine —
переиспользуется из основного пакета без изменений.

Тесты (31 штука, без сети, на заготовленных ответах API):

```bash
python -m unittest discover -s tests -t .
```

## Видеть цену и сделки вживую

```bash
python webui.py --mode dex
```

Переключатель источника под вкладками пар: **«Сделки бота»** — свой график
с метками входов и выходов, **DexScreener, GeckoTerminal и TradingView** — настоящие графики
этих сайтов во фрейме, со всеми их инструментами. Рядом ссылка «открыть на
сайте», если удобнее в отдельной вкладке.

Панель сама опрашивает рынок раз в несколько секунд, поэтому цена движется
в реальном времени — даже если торговый цикл не запущен. Режим «живая цена»
в селекторе показывает тиковую ленту за последние минуты.

В панели есть график, где видно каждый вход и выход по мере того, как
они происходят: ▲ покупка, ▼ продажа (цветом по результату), пунктир —
путь сделки, подсветка и линии стоп/тейк — открытая позиция, рядом живая
цена и текущий процент. Обновляется сам, работает и на бумажном счёте.

## Страница состояния одним файлом

```bash
python dexbot.py dashboard --open
```

Собирает самодостаточный HTML: эквити, позиции, стратегии, графики цены
с метками сделок и журнал. Открывается двойным кликом, сервер не нужен.
Чтобы файл обновлялся во время торговли: `python dexbot.py trade --dashboard`.

## Как за ботом следить

**В браузере** — `python webui.py --mode dex` откроет панель управления:
кнопки «Подобрать пары», «Найти стратегию», «Торговать», живой терминал,
график счёта, таблица сделок со ссылками на DexScreener и Solscan.


**В терминале** — каждое действие печатается на месте: подбор пар, найденные
стратегии, покупки и продажи с ценой, объёмом, стопом и тейком.

**В Telegram** — те же сообщения приходят в чат, если в `.env` заданы
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (те же, что у мем-коин сканера).
В каждом уведомлении о сделке есть ссылка на график пары в DexScreener, а при
реальных свопах — ещё и ссылка на транзакцию в Solscan:

```
🟢 Покупка WIF/SOL [solana:8sLbNZoA…]
цена 2.3405, объём 74.12 (≈173.50 USD)
стоп 2.2233, тейк 2.4276
стратегия #4 · бумажный счёт (DEX)
📈 график на DexScreener
🔗 транзакция в Solscan
```

**Командами, в любой момент:**

```bash
python dexbot.py report     # эквити, позиции, стратегии, последние сделки, ссылки на графики
python dexbot.py pairs      # что сейчас в работе: ликвидность, объём, стратегия
python dexbot.py backtest   # как активная стратегия отработала на истории
```

Отчёт можно смотреть параллельно с работающим ботом — он читает ту же базу.

**На графике** — открой ссылку из `report` или `pairs`: это тот же пул в
DexScreener (и он же виден в Axiom по адресу токена). Логику стратегии можно
посмотреть в TradingView: `python dexbot.py pine` соберёт скрипт со всеми
входами, выходами, стопом и тейком; конкретного DEX-пула в TradingView может
не быть, но на графике той же монеты правило видно целиком.

**В блокчейне** — при `--live` каждая сделка это транзакция: `solscan.io/tx/<подпись>`
из уведомления, либо просто адрес кошелька в Solscan, где видно все свопы и балансы.

Вся история хранится в `data/dex.db` (SQLite): таблицы `strategies`, `trades`,
`positions`, `equity`. Можно смотреть чем угодно, хоть `sqlite3`:

```bash
sqlite3 data/dex.db "SELECT ts, side, symbol, price, pnl, reason FROM trades ORDER BY id DESC LIMIT 20;"
```

## Ограничения, о которых стоит знать

- **Ни один запрос к DexScreener, GeckoTerminal и Jupiter не проверялся вживую** —
  в среде, где бот собирался, доступ к этим доменам закрыт. Код написан по их
  документированным схемам ответов и покрыт тестами на заготовках; первый
  реальный запуск делай через `discover --show-rejected` и `--dry`, посмотри,
  что данные приходят и разбираются как надо.
- GeckoTerminal отдаёт максимум 1000 свечей за запрос и держит ~30 запросов в
  минуту: на 15m это около 10 дней истории на пул.
- Свечи GeckoTerminal — цена **в этом конкретном пуле**, а Jupiter исполняет
  своп по лучшему маршруту, который может идти через другой пул. Небольшое
  расхождение цены — норма.
- Мем-токены живут неделями. Стратегия, найденная на истории такого токена,
  устаревает быстрее, чем на BTC, — поэтому `rediscover_hours` и `retrain_hours`
  здесь короче.
- Только лонг: бот покупает и продаёт, шортов на споте DEX нет.

Это инструмент, а не финансовый совет. На DEX теряют деньги быстрее и полнее,
чем где-либо ещё: торгуй только тем, что готов потерять целиком.
