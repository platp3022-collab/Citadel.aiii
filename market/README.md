# Market Dashboard & Trading Plan

Дневной институциональный бриф по вотчлисту: макро-контекст и риск-окна, мультитаймфреймовая
техничка, оценка качества сетапа 1–10 и план исполнения с точными уровнями входа, стопа и целей.

Отдельный инструмент, к мем-коин боту (`../memebot.py`) отношения не имеет.

## Твои инструменты, а не случайные акции

Вотчлист по умолчанию — то, что торгуется в терминале: золото, серебро, GER40,
NAS100, SP500, EURUSD, GBPUSD и крипта. Имена пишутся так, как они выглядят
у брокера, — перевод в биржевые символы инструмент делает сам:

| В терминале | Откуда берётся история |
| :--- | :--- |
| XAUUSD, XAGUSD | `XAUUSD=X`, при отказе `GC=F` / `SI=F` |
| GER40 | `^GDAXI` |
| NAS100 | `^NDX` |
| SP500 | `^GSPC` |
| EURUSD, GBPUSD | `EURUSD=X`, `GBPUSD=X` |
| BTCUSDT, ETHUSD, SOLUSDT, XRPUSD | `BTC-USD`, `ETH-USD`, `SOL-USD`, `XRP-USD` |

Кандидатов на символ несколько: берётся первый, который реально отдал историю.
В отчёте остаётся привычное имя, а рядом мелким шрифтом — под каким символом
данные взяты, чтобы не было сомнений, что именно посчитано.

Карта лежит в `ALIASES` в начале `market_dashboard.py`, дополняется одной строкой.

**Про индексы важно.** GER40, SP500 и NAS100 у брокера — это CFD, а история
берётся по самому индексу. Тренд, средние и уровни совпадают, торговать по ним
можно. Но цена и часы торгов отличаются от брокерских, поэтому сверять
котировку с терминалом не надо — для этого наверху страницы живые котировки
TradingView, там именно CFD.

## Сканер рынка

По умолчанию инструмент разбирает твой вотчлист. Но он умеет и сам искать
бумаги — пройти по всему списку S&P 500, посчитать технику по каждой и оставить
только те, где сетап реально есть:

```bash
python3 market_dashboard.py --scan             # 483 бумаги S&P 500
python3 market_dashboard.py --scan --keep 20   # оставить 20 вместо 12
python3 market_dashboard.py --scan мой_список.txt
```

Первый прогон занимает минуты — история качается по каждой бумаге. Дальше
всё лежит в кеше, и повторный скан проходит за секунды.

В отчёт попадают лучшие по скору плюс несколько самых громких имён из тех,
что скан забраковал, — чтобы секция «не трогаем» была не формальностью,
а списком того, что сегодня мозолит глаза и просится в сделку зря.

Вселенная лежит в `universe/sp500.txt`, это обычный текстовый список.
**Он составлен по публичному датасету и отражает состав индекса на 2018 год** —
часть бумаг выбыла, новые не попали. Свежий список бери в любом скринере
и просто замени строки в файле.

## Быстрый запуск

Windows — двойной клик по `run.bat`. Mac/Linux — двойной клик по `run.sh`
(или `chmod +x run.sh && ./run.sh` в терминале).

Бриф собирается как **веб-страница** и сам открывается в браузере.

Вручную:

```bash
python3 market_dashboard.py                     # тикеры из watchlist.txt
python3 market_dashboard.py NVDA AAPL BTC-USD   # тикеры из аргументов
python3 market_dashboard.py --md                # markdown вместо HTML
python3 market_dashboard.py --json --out b.json # машинный вывод
python3 market_dashboard.py --no-open           # не открывать браузер
python3 market_dashboard.py --offline           # только из кеша, без сети
python3 market_dashboard.py --self-test         # проверка математики
```

Зависимостей нет — нужен только Python 3.10+. Страница сохраняется в
`briefs/ГГГГ-ММ-ДД.html`, это обычный файл: можно переслать, распечатать в PDF
через «Печать» в браузере или открыть позже двойным кликом.

Формат можно не указывать флагом — он берётся из расширения `--out`
(`.html`, `.md`, `.json`).

**Инструмент должен работать на твоём компьютере.** Источники котировок (Yahoo Finance, Stooq)
закрыты для облачных песочниц — оттуда данные не тянутся.

## Откуда берутся цифры

| Что | Источник |
| :--- | :--- |
| Цены, объёмы, история | Yahoo Finance (без ключа), запасной — Stooq |
| 20 EMA / 50 SMA / 200 SMA | считаются локально по дневным закрытиям |
| Недельный тренд | дневные свечи сворачиваются в недельные (10 EMA / 30 SMA) |
| RSI(14), ATR(14) | сглаживание по Уайлдеру |
| RVOL | объём дня / средний объём за 20 предыдущих сессий |
| Экономический календарь | `events.json` — заполняешь сам |

Ответы кешируются в `data/cache` на 6 часов (`data/` не коммитится). Если оба источника
недоступны, берётся устаревший кеш с предупреждением в логе.

Тикеры в формате Yahoo: акции `NVDA`, крипта `BTC-USD`, ETF `SPY`, индексы `^GSPC`, форекс `EURUSD=X`.

## Экономический календарь

Бесплатного надёжного API по макро-событиям нет, поэтому календарь ведётся руками:

```bash
cp events.example.json events.json
```

События с `"impact": "high"` автоматически добавляют в бриф риск-окно: новых позиций нет
за 2 часа до релиза и 30 минут после. Дата отчёта в `earnings` за 2 дня до события уводит
тикер в секцию AVOID — гэп на отчёте не хеджируется стопом.

Без `events.json` бриф соберётся, но в секции макро будет явное предупреждение, что
календарь не загружен. Инструмент не выдумывает даты релизов.

## Как считается качество сетапа (1–10)

База 5.0, дальше прозрачные надбавки и штрафы:

| Фактор | Вклад |
| :--- | :--- |
| Согласованность тренда 1D и 1W | до +1.6 |
| Цена выше/ниже 200 SMA по направлению сделки | ±0.4 |
| RSI близко к рабочей зоне (58 лонг / 42 шорт) | до +0.9 |
| RSI перегрет (>78 лонг / <22 шорт) | −0.9 |
| RVOL выше единицы | до +1.0 |
| RVOL < 0.6 — участия нет | −1.0 |
| Отрыв от 20 EMA больше 2.5 ATR | −2.0 |
| Цена близко к 20 EMA | до +0.8 |
| 20-дневный диапазон уже 3 ATR (пила) | −1.0 |
| Близко к 20-дневному экстремуму | до +0.8 |
| Рост больше 45% за месяц — парабола | −2.0 |
| Отчётность в ближайшие 2 дня | −1.5 и блокировка сетапа |
| Новостной фон по/против техники | ±0.8 |

Слагаемые непрерывные, а не ступенчатые: RSI 57 и RSI 63 дают разный вклад,
а не одинаковый «в зоне». На вотчлисте из шести бумаг разницы не видно, но при
скане по всему рынку ступеньки сгоняли десятки бумаг в одинаковые 10.0/10,
и ранжировать было нечего.

Штраф за параболу — это то, что отсекает бумагу, которая уже проехала весь ход:
рост на 40–70% за месяц означает, что входить сейчас поздно, каким бы красивым
ни выглядел график.

Если 1D и 1W расходятся, направление не присваивается, а скор ограничивается 4.5 —
без согласованных таймфреймов направленного преимущества нет.

Ниже 6.0 тикер уходит в секцию AVOID. Пороги правятся в `CONFIG` в начале файла.

## Как строится план исполнения

- **Триггер** — ближайший значимый уровень по направлению сделки: вчерашний экстремум,
  20-дневный экстремум или годовой.
- **Стоп** — за структуру (20 EMA либо 20-дневный экстремум) плюс запас 0.25 ATR,
  но не шире 2 ATR от триггера.
- **Цели** — ближайший структурный уровень по направлению; если впереди чистое поле
  (новые хаи), берётся ATR-проекция 1.5 и 3.0.
- **Фильтр R:R** — если до T1 меньше 1.5R, сетап в план не попадает, вместо него
  строка «ждём вход ближе к 20 EMA».

Расписываются максимум 3 сетапа. Если ни один не прошёл фильтры, бриф прямо говорит
сидеть на руках.

В HTML каждый план рисуется «лестницей уровней»: стоп, триггер, T1 и T2 на одной шкале
с текущей ценой — сразу видно, сколько до входа и насколько цель дальше стопа.

## TradingView

По умолчанию котировки вверху страницы и верхний график берутся с TradingView —
через их **официальные бесплатные виджеты** для встраивания. Это даёт то, чего
не дают бесплатные API: живые цены текущего дня, индексные CFD (GER40, SP500,
NAS100), форекс и металлы, и их собственный график со всеми инструментами,
таймфреймами и рисованием. Бумагу можно сменить прямо внутри графика.

Их закрытый API я не трогаю: он не документирован, ломается без предупреждения
и его использование запрещено правилами сервиса. Виджеты — законный путь.

Виджеты грузят скрипт с домена TradingView, поэтому работают **только в локально
открытом файле с интернетом**. Если скрипт не поднялся, на его месте появляется
объяснение почему, а не пустая дыра.

Выключается в `live.json`:

```json
"tradingview": { "enabled": false }
```

Тогда вернётся своя панель на Binance и Finnhub — она проще, зато крипта в ней
идёт без всякой регистрации.

Соответствие символов подбирается само: `SP500` → `OANDA:SPX500USD`,
`GER40` → `OANDA:DE30EUR`, `BTCUSDT` → `BINANCE:BTCUSDT`, `EURUSD` →
`OANDA:EURUSD`, акции остаются как есть. Если для какой-то бумаги угадало
неверно, поле `tv` в `live.json` перебивает всё:

```json
{ "label": "GER40", "tv": "XETR:DAX" }
```

Собственные графики никуда не делись и идут следом за виджетом: они рисуют
уровни плана — стоп, триггер и цели, — которых TradingView знать не может,
и работают без интернета.

## Живые котировки

Наверху страницы — панель как в терминале: символ, цена, изменение, процент.
Цена тикает в реальном времени, при каждом изменении ячейка на полсекунды
подсвечивается зелёным или красным.

**Это работает только в локально открытом файле.** Страница сама держит
соединение с источником, поэтому вкладку нужно оставить открытой — закроешь,
поток оборвётся. В опубликованном в интернете виде котировки не пойдут:
там политика безопасности режет внешние запросы, и панель честно покажет
«нет связи» вместо выдуманных цен.

| Что | Источник | Ключ |
| :--- | :--- | :--- |
| Крипта | Binance, поток `@miniTicker` раз в секунду | не нужен |
| Акции, форекс, металлы | Finnhub, поток сделок | бесплатный |
| CFD на индексы (GER40, SP500, NAS100) | только API брокера | — |

Настройка — `live.json`:

```bash
cp live.example.json live.json
```

Крипта заведётся сразу, без регистрации. Для остального нужен бесплатный ключ
с [finnhub.io](https://finnhub.io/register) в поле `finnhub_key` — без него
некриптовые строки останутся серыми с прочерком. `live.json` не коммитится:
в нём лежит ключ.

Процент считается так же, как в терминале: у крипты от цены сутки назад,
у остального от вчерашнего закрытия (оно берётся один раз при загрузке,
дальше цену двигает поток сделок).

Про индексы честно: `GER40`, `SP500`, `NAS100USD` в твоём терминале — это CFD
брокера. У бесплатных источников их нет. Можно подставить сам индекс
(`^GSPC`, `^NDX`), но цена будет отличаться от брокерской — торговать по ней
нельзя, только смотреть направление.

## Графики

Два больших графика идут секцией сразу после макро-фона.

**Сверху — дневной график сетапа дня.** Свечи за 130 сессий, три скользящие средние
(20 EMA / 50 SMA / 200 SMA), объём под ценой и уровни плана прямо на полотне: стоп,
триггер, T1 и T2 пунктиром с подписями. Видно не только «где цена», но и где именно
проходит граница, за которой сделка перестаёт быть валидной.

**Снизу — относительная динамика вотчлиста.** Все тикеры от общей базы в процентах:
кто ведёт, кто отстаёт. Именно эта картинка отвечает на вопрос «а не покупаю ли я
самое слабое имя в секторе».

**Графики живые, как в терминале.** Колесо мыши (или щипок на тачскрине) — зум вокруг
курсора, перетаскивание — листание истории, двойной клик — возврат к исходному виду.
Перекрестие тянет за собой подписи прямо на осях: дату снизу, цену справа. Строка над
графиком показывает O/H/L/C, изменение и объём того бара, на который наведён курсор —
на нижнем графике вместо этого идут проценты сразу по всем тикерам.

В браузер отдаётся вся загруженная история (по умолчанию 760 сессий), а видно при
открытии последние 130 — остальное отлистывается назад. Шкала цены пересчитывается
под видимое окно, а проценты на нижнем графике считаются от левого края окна: отлистал
назад — сравнение перестроилось от новой точки отсчёта.

Полотно рисуется в реальных пикселях и пересчитывается при изменении ширины окна,
поэтому подписи осей не мельчают на телефоне. На узком экране подписи уровней
сокращаются до значений, а лишние метки месяцев убираются.

Цвета средних — порядковая шкала одного тона: чем медленнее средняя, тем темнее линия.
Линии тикеров используют категориальные слоты 1–5 и 7 стандартной схемы; слоты 6 и 8
(зелёный и красный) намеренно пропущены, потому что на этой странице зелёный и красный
уже означают направление, и линия такого цвета читалась бы как оценка, а не как имя.
Палитра прогнана валидатором в обеих темах, включая проверку на дальтонизм.

## Страница

Одностраничный HTML без внешних зависимостей (шрифты — Google Fonts с запасным стеком).
Подстраивается под тему системы, есть кнопка ручного переключения. В таблице —
спарклайны за 60 сессий, цветные бейджи тренда 1D/1W и шкала качества сетапа.
На узком экране таблица и графики скроллятся внутри себя, страница вбок не едет.

## Проверка

```bash
python3 market_dashboard.py --self-test
```

Гоняет индикаторы против независимых реализаций и эталонных значений RSI по Уайлдеру,
проверяет свёртку недель, границы скоринга, направление целей и то, что отчётность
завтра действительно блокирует сетап. Сеть не нужна.

---

Инструмент фильтрации информации, не финансовый совет. Уровни считаются от истории цены
и ничего не знают о твоём риск-менеджменте и размере депозита.
